# Welcome to HierGen!!!

HierGen is a small package that helps you process free form
text from a variety of types of sources that use indentation
to express hierarchy.

An example of data with hierarchy by indentation is:

```
USA
    Washington
        Seattle
    Wisconsin
        Madison
Canada
    British Columbia
        Vancouver
    Alberta
        Calgary
```
